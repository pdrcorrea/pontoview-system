# PontoView Screens

Frontend independente da plataforma de mídia indoor PontoView.

## Direção do produto
A aplicação controla telas, playlists, programações e PontoView Apps. Mídias pesadas não serão armazenadas pela PontoView no MVP: o Google Drive do cliente será a origem dos arquivos.

## Stack
- React + TypeScript + Vite
- React Router
- TanStack Query
- Supabase
- Lucide React

## Módulos iniciais
- Dashboard
- Conteúdo
- Playlists
- Programações
- Telas
- PontoView Apps
- Player fullscreen
- Configurações

## Próxima etapa
Implementar autenticação multiempresa e o modelo de dados com RLS, seguindo o padrão de isolamento já adotado no BusBoard, mas com tabelas e frontend próprios da PontoView.
